¿Cómo funciona este modelo? (§46 Explicación ejecutiva)

      

        
Primero estimamos cuándo y cuánto vende cada sucursal durante el año. Luego convertimos esa demanda en cajas y calculamos cuánto inventario debe mantenerse de acuerdo con el DOH definido para fresco y congelado. Comparamos ese inventario con la capacidad física disponible de cada cámara. Paralelamente calculamos si existen suficientes horas, productividad y personas para procesar la demanda. Finalmente consolidamos el comportamiento completo del año sin perder los peaks ni la duración de los periodos de tensión.

        
El modelo mide saturación. No decide cómo resolverla.


        
Arquitectura de cálculo (§48)

        
Datos maestros → Demanda anual → Estacionalidad sucursal → Distribución Lun–Sáb → Demanda diaria kg → Kg/caja → Cajas → DOH → Inventario estructural → Push/On Hand → Inventario observado → Capacidad física kg → Saturación fresco / congelado → Saturación física sucursal (ponderada por capacidad)

        
En paralelo: Cajas → Productividad → HH requeridas → Saturación operacional · Personas requeridas → Dotación → Saturación dotación · Personas → Espacio operacional → Saturación espacio-personas


        
Dimensiones que se mantienen SIEMPRE separadas (§19)

        
    
          
  • Físico estructural — inventario del DOH vs capacidad geométrica.
    • 
          
  • Físico observado — inventario estructural + push extraordinario.
    • 
          
  • Fresco y Congelado — nunca se ocultan en el consolidado.
    • 
          
  • Operacional — cajas demandadas vs capacidad de proceso (HH × productividad).
    • 
          
  • Dotación — personas requeridas vs personas disponibles.
    • 
          
  • Espacio-personas — personas requeridas vs máximo físicamente operable.
    • 
        

        
Prohibido: promediar (Físico + Operacional + Personas) / 3. Son restricciones distintas y se reportan por separado, cada una con índice anual, peak, P95 y exposición.


        
Capacidad desde geometría (§12)

        
CAPkg = M² × Altura_útil × Factor_utilización × Densidad_kg/m³

        
No se usan posiciones pallet como capacidad principal: reflejan el layout actual y pueden inducir falsa falta de capacidad.


        
Estructural vs Observado (§11, §24)

        
El push (stock extraordinario) se mantiene completamente separado del inventario estructural. Nunca se modifica el DOH para absorberlo. Se reportan ambos escenarios y el impacto en puntos porcentuales.


        
Lo que la herramienta NO hace (§43)

        
No recomienda construir, ampliar, cerrar, redistribuir volumen, comprar rack, contratar personas ni cambiar el DOH. Entrega únicamente el diagnóstico matemático, auditable y trazable, para que otro modelo decida.
